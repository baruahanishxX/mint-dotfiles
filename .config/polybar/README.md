# Polybar Configuration

Status bar configuration tailored for XFCE desktop environments on Linux Mint.

## Included Modules

| Module | Function |
| :--- | :--- |
| **Workspace Indicator** | Tracks active XFCE workspaces |
| **Window Title** | Displays active application title |
| **Hardware Monitors** | Real-time CPU and Memory usage tracking |
| **Network Traffic** | Live upload and download throughput |
| **System Info** | Battery indicator, volume, and clock |
