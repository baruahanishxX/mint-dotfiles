# Kitty Terminal Configuration

Modular configuration for the Kitty terminal emulator, featuring a Nord color palette, background transparency, and custom font rendering.

## Specifications

| Setting | Value |
| :--- | :--- |
| **Font Family** | JetBrainsMono Nerd Font |
| **Font Size** | 10 pt |
| **Color Scheme** | Nord (Dark) |
| **Background Opacity** | 0.85 |
| **Cursor Style** | Block (Blink: Disabled) |
